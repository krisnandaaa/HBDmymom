# 🌸 Happy Birthday, Mama 🌸

Website ucapan ulang tahun yang cantik untuk Mama tersayang, dibuat dengan penuh cinta.

## ✨ Fitur

- 🌸 **Animasi Bunga Sakura** — Kelopak sakura berjatuhan cantik di seluruh layar menggunakan Canvas API
- 🎂 **Kue Ulang Tahun** — Gambar kue yang indah dengan efek berkilau, lengkap dengan interaksi "Tiup Lilin"
- 💖 **Pesan Cinta** — Ucapan tulus dengan desain elegan bergaya glassmorphism
- 📸 **7 Bingkai Foto** — Tempat untuk mengunggah foto-foto kenangan bersama Mama
- 🌟 **Doa dan Harapan** — Empat kartu doa yang animatif
- 🎉 **Efek Konfeti** — Pecahan konfeti warna-warni saat meniup lilin
- 📱 **Responsif** — Tampil sempurna di semua perangkat

## 🎨 Tampilan

- Tema warna **pink elegan** dengan gradasi lembut
- **Glassmorphism** pada kartu dan bingkai foto
- **Tipografi premium** menggunakan Playfair Display + Lato
- **Micro-animations** pada setiap elemen untuk tampilan yang hidup
- **Scroll-triggered animations** saat menggulir halaman

## 🚀 Cara Menggunakan

### Buka Langsung di Browser
Cukup buka file `index.html` di browser manapun — tidak perlu server!

### Upload ke GitHub Pages
1. Push semua file ke repository GitHub kamu
2. Buka **Settings** → **Pages**
3. Pilih branch `main` dan folder `/ (root)`
4. Klik **Save** — website akan aktif di `https://[username].github.io/[repo-name]`

### Personalisasi
- Edit teks di `index.html` (nama, pesan, dll.)
- Klik setiap bingkai foto untuk upload foto kenangan
- Kustomisasi warna di `style.css` pada variabel CSS di `:root`
